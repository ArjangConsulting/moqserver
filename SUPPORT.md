# Support

Use GitHub Issues for reproducible bugs, documentation problems, and focused feature requests.

Before opening an issue:

- search existing issues
- verify the latest `main` branch still has the problem
- remove real credentials and private API data from examples

For usage questions, include the command you ran, the input format (`OpenAPI`, `HAR`, or `.moqproj`), and the relevant error output.

Security reports should follow [`SECURITY.md`](SECURITY.md), not public issues.
