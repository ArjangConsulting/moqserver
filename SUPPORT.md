# Support

Use GitHub Issues for reproducible bugs, documentation problems, and focused feature requests.

Before opening an issue:

- search existing issues
- verify the latest `main` branch still has the problem
- remove real credentials and private API data from examples

For usage questions, include the product and version, operating system, command or Studio workflow, `.moqproj` format version, and relevant error output.

Only the latest stable release and current `main` branch are actively supported. Best-effort help is available for prereleases; older releases should first be reproduced on the latest stable version.

Security reports should follow [`SECURITY.md`](SECURITY.md), not public issues.
